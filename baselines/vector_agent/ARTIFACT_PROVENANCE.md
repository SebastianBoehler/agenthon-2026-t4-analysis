## Executive summary

This record accompanies the vector-agent build source. On 10 October 2026,
all three global interval multipliers were replaced with identity values (1.0).
This choice preserves pooled model intervals and the existing corpus-derived floor
without empirical rescaling. It does not depend on prediction accuracy.

The earlier candidate had private-outcome-informed choices. Those choices and
their research history remain disclosed below. This source checkpoint is not a
new image, submission, verified production score or complete Final qualification.

## Authority and cutoff treatment

The [organizer's 9 October ruling](https://github.com/Agenthon-2026/track4-analysis-public/issues/24#issuecomment-6090644107)
covers keeping, dropping and changing code as well as fitting constants.
Private scores cannot affect what Final submits unless their outcome version
predates every applicable task cutoff. Final cutoffs are unpublished, so this
record does not assume eligibility for the separate research evaluation set.

The ten public practice units' first-published outcomes are a separate exception.
This identity correction uses no outcome-based selector and claims no practice
exception. Any future practice-based choice needs named units, each value's
source, retrieval date and first-publication provenance recorded with its source.

The current grounds are mathematical identity, code correctness and bounded
resource use. Correctness means implementing the stated mechanism, not predictive
accuracy. Research history is retained; no prior outcome-based decision is
retrospectively renamed diagnostic-only. The organizer requires no signoff.

## Inputs and model sources

- Runtime predictions use the organizer-injected House route, mounted task,
  entity roster and admitted corpus. No participant model or adapter is bundled.
- Evidence timestamps, document identities and entity admission come from the
  mounted manifest. Runtime evidence must satisfy the unit's actual cutoff gates.
- Sample points, labels and intervals come from runtime model responses. Growth
  arithmetic uses declared bases in the task table. The band floor uses dated
  corpus histories; neither mechanism reads realized target outcomes.
- Historical research used a separately hosted Nemotron 3 Super proxy. Its
  provider, quantization, timing and reasoning are not confirmed House parity.
- Public synthetic tests contain invented entities and values. Protected outcomes,
  answer mappings, credentials, saved task answers and experiment receipts stay
  outside this repository and are not build inputs.

## Identity correction and validation

The correction starts from source commit
`60abd417a157caed792b3e0cc0a289cb3f7ac485`. The former source and submitted RC15
artifacts remain immutable in Git and private scientific records. The correction
was frozen before implementation and uses only synthetic correctness controls.

Identity scaling preserves points, labels and sample pools at the numeric tail;
the existing corpus floor still applies. Large-roster answer-cap rounding depends
on interval width and can change serialized points. No universal final-byte point
identity or interval-calibration guarantee is claimed.

Relevant checks exercise the actual production numeric tail, asymmetric intervals,
classification branches, weighted disagreement, corpus floor and percent-to-bps
conversion, threshold labels, and the within-cap CLI/schema path. Existing
scheduling and parsing controls remain relevant. Passing them establishes code
behavior, not official prediction performance or unseen-family transfer.
